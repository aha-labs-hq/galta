# Provider marks

Monochrome marks for the generation providers in the Settings dialog, drawn in the
surrounding text colour through a CSS mask.

- `openrouter.svg`: Lobe Icons at commit `c385b2b8d1f9e19aa86e628d4e23c91ee1111a47`
  (`packages/static-svg/icons/openrouter.svg`, static SVG package 1.95.1, MIT; see `LICENSE`).
- `fal.svg`: Lobe Icons, the same commit and package (`packages/static-svg/icons/fal.svg`).
- `byteplus.svg`: the BytePlus logo from BytePlus's site
  (`https://sf-bpcms.bytepluscdn.com/obj/byteplus-assets/navigation/byteplus_logo_footer.svg`),
  with its white fill changed to `currentColor`. Lobe Icons has no BytePlus mark.
- `higgsfield.svg`: the glyph of the Higgsfield logo in the header of `https://higgsfield.ai`,
  already drawn in `currentColor`. Lobe Icons has no Higgsfield mark.

Served locally; no external requests. Marks identify the integration, not a
partnership, and remain the property of their owners.
