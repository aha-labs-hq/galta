# Contributing

Galta is made by a small team with a particular design direction. Anyone can
open an issue; pull requests are accepted only from members of the Aha Labs
organization, and a bot closes others with a link here. That says nothing about
the quality of your work.

What helps:

- **Bug reports.** Open an issue with what you did, what you expected, what
  happened instead, and your Galta version, browser and macOS version. A
  screenshot or screen recording is often the fastest way to show it.
- **Ideas.** Open an issue that starts from the problem you ran into rather
  than the feature you would build. The problem is what we can design for.
- **Security problems.** Do not open a public issue; follow
  [SECURITY.md](SECURITY.md).

Members: this repository is published from Galta's development repository at
each release, so an accepted pull request reaches `main` with the next release
rather than by being merged here, and is closed when that release is published.

You are free to read, build and fork the code under its [license](LICENSE).
